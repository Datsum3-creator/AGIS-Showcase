# AGIS - Demo Information



## Current Prototype



AGIS has an early-stage working prototype demonstrating core agent inventory and governance workflows.



## Demonstration Environment



The prototype currently runs locally using:



- Frontend: HTML, CSS, JavaScript

- Backend: FastAPI

- Database: PostgreSQL



## Demonstrated Workflows



- User authentication.

- Role-based access.

- Agent registration and inventory.

- Agent review and approval/rejection.

- Organization-level access separation.

- Operational status updates.

- Selected audit events.



## Demo Availability



**Status:** Local prototype.



A public hosted demo is not currently available.



A demonstration walkthrough or screenshots may be added here as they become available.



## Important Limitation



The prototype does not currently provide automated Shadow AI discovery, runtime agent termination, credential revocation, or production-grade deployment.
