# AGIS - Development Roadmap



**AI Agent Governance & Inventory System**



Our roadmap separates the current prototype from future development goals. Planned capabilities are not represented as completed features.



## Phase 1 - Core Governance Prototype



**Status: Core prototype demonstrated**



- [x] JWT-based authentication.

- [x] Admin, Reviewer, and Viewer roles.

- [x] AI agent registration and inventory.

- [x] Agent details and dashboard integration.

- [x] Organization-level tenant isolation tested.

- [x] Reviewer approval and rejection workflow.

- [x] Separation-of-duties validation.

- [x] Operational status management.

- [x] Selected audit event recording.

- [x] Frontend integration with backend APIs.



## Phase 2 - Prototype Hardening



**Status: Next development focus**



- [ ] Complete frontend and backend integration testing.

- [ ] Improve error handling and input validation.

- [ ] Strengthen human ownership enforcement.

- [ ] Improve audit history and dashboard accuracy.

- [ ] Clean demo data and prepare a repeatable demonstration.

- [ ] Conduct a structured security review.

- [ ] Improve automated test coverage.



## Phase 3 - Developer-Native Governance



- [ ] Introduce the `agis.yaml` agent manifest.

- [ ] Build registration and validation workflows.

- [ ] Track agent versions and lifecycle changes.

- [ ] Improve connected-tool and permission visibility.

- [ ] Explore CI/CD integration.



## Phase 4 - Discovery and Runtime Governance



- [ ] Research Shadow AI discovery approaches.

- [ ] Develop agent discovery and inventory reconciliation.

- [ ] Explore runtime monitoring.

- [ ] Design policy enforcement mechanisms.

- [ ] Investigate credential revocation and safe termination integrations.



## Phase 5 - Enterprise Readiness



- [ ] Enterprise identity integrations.

- [ ] Expanded compliance and governance reporting.

- [ ] Cloud deployment architecture.

- [ ] Scalability and performance testing.

- [ ] Independent security assessment.

- [ ] Pilot validation with prospective organizations.



## Current Status



**Early-stage working prototype - under active development.**



The roadmap is directional. Timelines and completion dates will be established as development progresses.
